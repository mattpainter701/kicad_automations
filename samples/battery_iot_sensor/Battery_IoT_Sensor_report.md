## Design Rationale

### U1 — MCP73831T-2ACI/OT

- Charge VBAT: 0.5A into 4.2V cell from VBUS_5V
- Rprog = 1000 / 0.5A = 2k (actual 0.500A)
- Cin=4.7uF, Cbat=4.7uF
- Thermal: Pdiss = (Vin - Vbat) * Ichg = (5.0V - 4.2V) * 0.5A = 0.40W

### U2 — MAX17048G+T

- Fuel gauge MAX17048G+T: ModelGauge (voltage-based)
- Cell capacity: 2000mAh, I2C addr: 0x36
- CELL filter: 100R + 1uF
- QSTRT pulled low (quick start disabled)

### U3 — MCP1700-3302E

- VDD_3P3: 3.3V from VBAT at 0.25A (MCP1700-3302E)
- Dropout: 0.178V, Pdiss: 0.10W, Iq: 1.6uA

### RP1 — PULLUPS_ONLY

- I2C pull-ups: 3.6k to VDD_3P3 (3.3V)
- Speed: 400kHz, C_bus=100pF
- R = t_rise / (0.8473 * C_bus) = 3541 -> 3.6k
