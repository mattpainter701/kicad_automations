🔧 Example: WiFi Environmental Sensor

This demo builds a complete IoT device with:

  • Power Stage: 3.7V battery → 5V boost (MT3608, 1A) → 3.3V buck (AP62300, 800mA)
  • MCU: ESP32-WROOM-32E (WiFi + 4MB flash)
  • Sensor: BME280 (temperature, humidity, pressure via I2C)
  • Board: 102 × 69 mm, 2-layer, ready for JLCPCB assembly

Design Specification (design.yaml)

project: WiFi_Sensor_v1 description: Battery-powered WiFi environmental sensor power: - type: boost # 3.7V → 5V, 1A ref: U1 ic: MT3608 vin: 3.7 vout: 5.0 iout: 1.0 rail_name: VBUS_5V - type: buck # 5V → 3.3V, 800mA ref: U2 ic: AP62300 vin: 5.0 vout: 3.3 iout: 0.8 rail_name: VDD_3P3 digital: - ic: ESP32-WROOM-32E ref: U3 sensors: - ic: BME280 ref: U4

🎯 Key Features Demonstrated

  • Zero manual calculations: Resistor/capacitor values computed from IC datasheets
  • Full ERC/DRC: Validates feedback dividers, decoupling coverage, voltage ratings
  • Auto-placement: Components arranged for optimal power flow and signal integrity
  • Real-time pricing: LCSC price tiers queried at qty breaks (1, 10, 100, 1000)
  • LLM-native: Every step uses real CLI commands—Claude Code, Codex, OpenCode can execute them directly
  • Production-ready: JLCPCB/PCBWay assembly files generated immediately
